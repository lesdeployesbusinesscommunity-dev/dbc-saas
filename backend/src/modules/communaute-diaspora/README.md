# Module 9 — Communauté et diaspora

Squelette en attente d'implémentation. Suivre le même cycle que le module
`identite-acces` déjà construit :

1. **domaine/** — écrire les entités et règles métier, avec leurs tests unitaires,
   avant tout code d'infrastructure.
2. **application/** — un use-case par cas d'utilisation du cahier de conception.
3. **infrastructure/** — adaptateur(s) implémentant les ports définis dans le domaine.
4. **interface/** — DTO (class-validator) + contrôleur REST, exposés sous `/api/v1/...`.

Référence : cahier de conception, section "Module 9 — Communauté et diaspora" (cas d'utilisation,
diagramme de classes, diagrammes d'activité).
